# domain-feed

Fahad-এর ডোমেইন স্লিপার এজেন্টের জন্য ডাটা ফিড। GitHub Actions দিনে দুবার GoDaddy Auctions inventory আর Dynadot-এর নিলাম লিস্ট নামায়, স্কিলের hard filters দিয়ে ছাঁকে (.com/.si, $50-এর মধ্যে, হাইফেন/সংখ্যা ছাড়া, অর্থহীন অক্ষরগুচ্ছ বাদ), আর ফলাফল `data/` ফোল্ডারে রাখে:

- `data/candidates.csv`: কেনার মতো ক্যান্ডিডেট (সর্বোচ্চ ৪০০টা)
- `data/ai_watch.csv`: .ai watchlist (সর্বোচ্চ ১০০টা)
- `data/run_log.txt`: কোন সোর্স কাজ করেছে, কতগুলো নাম এসেছে

সকালের Claude এজেন্ট এই ফাইলগুলো পড়ে মূল্যায়ন করে। এই স্ক্রিপ্ট কখনো বিড বা কেনাকাটা করে না।
